# HP 3052 Network Scanner

Старый МФУ может оставаться полностью исправным, но после перехода на Windows 10/11 сетевое сканирование становится проблемой: печать работает, а сканер недоступен в привычных приложениях или старое программное обеспечение не удаётся использовать. Из-за этого рабочую технику приходится подключать иначе или задумываться о её замене.

Этот проект создан, чтобы вернуть сетевое сканирование на HP LaserJet 3052 и продлить срок службы устройства. Он использует драйвер HPLIP/SANE через WSL и Ubuntu, а управление сканированием, обработка страниц и сохранение документов доступны в отдельном приложении с русским интерфейсом Windows.

Приложение для сетевого сканирования на HP LaserJet 3052 в Windows 10/11 x64. Русский интерфейс, сканирование со стекла и из автоподатчика, обработка страниц и сохранение многостраничных документов.

![Иконка сканера](src/Assets/scanner.svg)

## Возможности

- Сканирование со стекла и пачки листов из автоподатчика.
- Предпросмотр доступной области стекла и сканирование выделенного участка.
- Выбор размера, разрешения и цветового режима; профили сканирования.
- Поворот, ручная обрезка, перестановка и удаление страниц.
- Автоматическое выравнивание наклона текста до ±5°, обрезка пустых полей с настраиваемым отступом и улучшение читаемости.
- Сравнение оригинала и обработки перед применением, отмена и повтор изменений.
- PDF, JPG, PNG, TIFF и BMP; автоматическое предложение имени файла.
- Восстановление текущего проекта и резервирование настроек.

## Обновление работающей программы

1. Закройте старое приложение.
2. Распакуйте ZIP целиком в новую постоянную папку.
3. Откройте `START.cmd` или `app/HP3052Scanner.exe`.

При запуске под той же учётной записью Windows используются прежние настройки и проект. Рабочую Ubuntu переустанавливать не нужно. Старый ярлык может вести в старую папку: запускайте новую версию из распакованного архива.

## Первая установка

Нужны Windows 10/11 x64, сетевое подключение к сканеру и интернет для первоначальной настройки.

1. Распакуйте готовый архив целиком, например в `C:\HP3052Scanner`.
2. Запустите `INSTALL-UBUNTU.cmd`. Он проверяет WSL и подготавливает Ubuntu. Если потребуется перезагрузка, перезагрузитесь и повторите запуск этой команды.
3. Запустите `INSTALL.cmd`: установка пакетов сканера, ввод адреса HP 3052 и создание ярлыков.
4. Откройте `START.cmd`, затем нажмите **«Проверить связь»**.

WSL1, Ubuntu 22.04 и HPLIP/SANE необходимы для работы со сканером. Они используются и после первоначальной настройки.

Подробная простая инструкция: [Инструкция для новичка](docs/Инструкция.txt).

## Автообработка

Выберите страницу → **«Автообработка…»** → сравните оригинал и результат → **«Применить»**. Обычно достаточно поля 3 мм и режима **«Бережно»**. После изменения параметров нажмите **«Обновить предпросмотр»**. **Ctrl+Z** возвращает исходную страницу, **Ctrl+Y** повторяет обработку.

Обработка исправляет небольшой наклон текста. Для страницы боком используйте поворот на 90°. Обрезка ищет содержимое, а не углы листа; перспективу не исправляет. Бледный текст, пятна и тени могут влиять на границы — проверьте предпросмотр. История отмены действует до закрытия приложения.

## Сборка из исходников

Для разработки нужен .NET 8 SDK в Windows. Выполните:

```bat
BUILD-WINDOWS.cmd portable
```

Готовый автономный EXE появится в `app`. Без аргумента `portable` сборка требует установленной .NET Desktop Runtime 8 x64.

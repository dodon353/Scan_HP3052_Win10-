ПРОВЕРКА НА WINDOWS — 0.7.0
Сначала закройте старую версию и используйте новую папку.

1. BUILD-WINDOWS.cmd → START.cmd; заголовок и кнопки помещаются на экране.
   RUN-TESTS.cmd должен пройти Core, WindowsImages и PowerShell.
2. Проверьте связь со стеклом и автоподатчиком. Ни один запрос проверки
   не подаёт бумагу. Проверьте доступные DPI, в том числе исходно выбранные 75.
3. На Auto|ADF напоминание появляется один раз за запуск. Уберите бумагу
   из лотка, подтвердите его; предпросмотр и область не должны спрашивать снова.
   Снимите флажок напоминания и перезапустите приложение: настройка сохраняется.
4. Выберите «Фото 10×15», сделайте предпросмотр: он должен охватить всю
   доступную область стекла. Проверьте драйвер с минимальным DPI 100, если есть.
5. Отсканируйте 3 страницы. Ctrl+Z и кнопка отмены не должны удалять сканы.
   Переименуйте страницу, отсканируйте ещё одну, нажмите Ctrl+Z:
   имя откатывается, все четыре скана остаются. Ctrl+Y возвращает имя.
6. Выберите несколько страниц Ctrl/Shift, удалите; одна отмена возвращает все.
   Перетащите несколько миниатюр вместе, проверьте их относительный порядок;
   одна отмена возвращает прежний порядок, повтор снова перемещает.
7. При пустой истории Undo/Redo недоступны. Ctrl+Z в поле ширины, высоты,
   качества JPEG и имени не должен менять документ.
8. Увеличьте страницу и переместите изображение. Переименуйте страницу:
   масштаб и положение должны сохраниться. Проверьте +, −, 0, F, W,
   стрелки, Escape при фокусе в изображении.
9. Проверьте поворот 90°/180°, обрезку, Undo/Redo и сохранение размеров PDF.
   Во время обработки окно должно перерисовываться, на «Отмена» реагировать;
   отмена ожидает завершения текущего кодека и не повреждает исходную страницу.
10. Восстановите документ 20–30 страниц в 600 DPI. Проверьте, что окно
    остаётся доступным во время последовательной загрузки миниатюр.
    Быстро меняйте выбранную страницу: итоговый просмотр должен соответствовать
    последней выбранной миниатюре. Измерьте память, без обещания фиксированного лимита.
11. ADF: пустой лоток; пачка; окончание бумаги; замятие; отмена; закрытие
    во время сканирования; восстановление подтверждённых страниц после перезапуска.
12. В тестовой копии проекта создайте пакет batch_* с request.json,
    двумя корректными page_*.tiff с маркерами .complete и одной повреждённой TIFF.
    При восстановлении корректные страницы должны быть видны; повреждённая
    остаётся в исходниках пакета. Реальный сбой при сканировании должен давать
    такой же видимый результат без необходимости вручную обновлять список.
13. При закрытом приложении сохраните копию settings.json, затем повредите
    тестовый файл. Запуск должен предупредить и создать .corrupt_*.bak;
    .bak прежних корректных настроек не должен затираться повреждённой копией.
    При недоступной для записи папке запуск/сохранение должны сообщать ошибку.
14. Повредите тестовый session.json. Проверьте создание папки _recovery_*.
    Если её перемещение запрещено правами/блокировкой, запуск должен остановиться
    с объяснением и не стирать исходную папку.
15. Экспортируйте Color/Gray/Lineart в PNG/TIFF/PDF. Сравните 24/8/1-bit,
    пиксели, размеры страниц, качество и размеры файлов. Проверьте JPEG-качество,
    единый PDF, выборочный экспорт, дату, имена, отказ от перезаписи и отмену.
16. Введите действующее сетевое имя аппарата. После изменения IP в DHCP
    новое задание должно разрешить имя заново. Проверьте «Найти HP 3052»;
    отсутствие находок не должно мешать ручному вводу.
17. Проверьте масштаб Windows 100/150/200% и перенос между мониторами:
    миниатюры масштабируются, текущий просмотр после смены DPI остаётся доступным.
18. «Очистить временные файлы»: сначала отказ, затем подтверждение.
    Текущие страницы и файлы Undo/Redo должны сохраниться. Старые резервные
    проекты удаляйте только после проверки их содержимого. После нормального
    закрытия неиспользуемые версии PNG удаляются; текущий документ восстанавливается.

Пункты с настоящим аппаратом, GUI и кодеками не выполнены в Linux.
Не проверяйте повреждение/удаление на единственной копии нужных сканов.

РЕГРЕССИЯ 0.6.1
- Предпросмотр должен пройти вместо прежнего --br-x Invalid argument.
- Проверьте, что после изменения формата Фото/A4 размер обзора остаётся
  исходным размером драйвера, а не выбранного формата.
- Выделите область внутри обзора и сравните результат с положением оригинала.
- Проверьте обычный A4, свой размер и режим всей доступной области.
- В журнале Glass scan request для предпросмотра содержит DriverDefaultArea=true;
  для выделенной области — false. При ошибке пришлите параметры и ответ драйвера.

РЕГРЕССИЯ СОХРАНЕНИЯ 0.6.2
- В главном окне нет поля «Имя документа» и флажка даты.
- По очереди выберите PDF/JPG/PNG/TIFF/BMP. В каждом случае должно открыться
  «Сохранить как» с автоматически предложенными именем и расширением.
- Измените имя в диалоге. Одна страница сохраняется точно под этим именем.
- Для нескольких отдельных страниц задайте основу «Договор»: проверьте
  Договор_001, Договор_002 и т. д., отсутствие файла без номера.
- С включённым «Один PDF» создаётся один PDF с выбранным именем.
- Проверьте кириллицу, jpeg/tif, отмену диалога и отказ от перезаписи.
- Снова сохраните в ту же секунду: предлагается свободное имя.
- После сохранения одной страницы «Открыть результат» открывает файл;
  после пакета — папку. «Только выбранные» и экспорт перед выходом работают.

АВТООБРАБОТКА 0.7.0
1. Выберите текстовый скан с небольшим наклоном → «Автообработка…».
   Сравните оригинал/результат, проверьте сохранность подписей и номера страницы.
2. Измените поле 3→10 мм, обновите предпросмотр: поля увеличиваются.
   Отключите обрезку: холст целиком остаётся видимым.
3. Сравните «Бережно»/«Сильнее» на серой бумаге, цветной печати и бледном тексте.
   Сильный режим может убирать оттенки: при необходимости оставьте бережный.
4. Примените → Ctrl+Z → Ctrl+Y. Оригинал и результат восстанавливаются,
   число страниц не меняется, новый скан через Undo не исчезает.
5. Отмените диалог; закройте его во время расчёта предпросмотра; отмените
   обработку полного скана. Незавершённая версия не должна попадать в документ.
6. Проверьте пустой лист, страницу без уверенного наклона, страницу боком,
   фотографию и документ с тенью у края: при ошибочных полях отключите обрезку.
7. Проверьте чёрно-белую страницу с наклоном: результат в оттенках серого,
   Undo возвращает исходный 1-bit режим. Сохраните в PDF, PNG, JPG и TIFF.
8. На 100/150/200% DPI окно сравнения должно помещаться в рабочую область,
   параметры и кнопки видны. На узком окне кнопка панели доступна через >>.

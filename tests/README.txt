ВОСПРОИЗВОДИМЫЕ ПРОВЕРКИ 0.7.0

Исходники тестов находятся здесь и используют ../src из того же архива.
Не нужны сторонние NuGet-библиотеки или настоящий сканер.
Требуется .NET SDK 8; для Windows-тестов — Windows x64 с Desktop Runtime 8.

WINDOWS
В корневой папке запустите RUN-TESTS.cmd.
Он вызывает tests/Run-Tests.ps1 и создаёт новую папку test-results-<GUID>.
Запускаются:
- CoreTests.csproj --skip-process: 217 проверок файлов/моделей/PDF;
- WindowsTests.csproj: 36 проверок настоящих Windows-кодеков и viewer;
- settings-tests.ps1: 13 проверок PowerShell.
WindowsTests здесь только скомпилирован, результат его выполнения не заявляется.
Саму графику и аппарат проверяйте по WINDOWS-CHECKLIST.txt.

LINUX
Нужны SDK .NET 8, Python 3, bash и PowerShell 7 (pwsh в PATH).
Из корня пакета: bash tests/run-linux.sh
Он выполняет CoreTests вместе с 23 тестами процессов (в сумме 240),
затем 13 PowerShell-проверок. fake-wsl.sh и scanimage имитируют ответы
и подменяют исполняемый файл только в тестовом процессе.
wsl-fixture.py воспроизводит отмену до публикации PID: Linux-задание
отделено от дерева процессов запускающего его приложения, как в реальном WSL.
Процессные тесты не выполняют установку WSL/пакетов, не обращаются к сканеру
и не убивают чужие процессы. На Windows их автоматически пропускают.

НЕЗАВИСИМАЯ ПРОВЕРКА PDF
При установленных Poppler (pdfinfo, pdftoppm, pdfimages) и Python Pillow:
python tests/verify-pdfs.py <папка-core-результатов>
Она отрисовывает Gray, Lineart и Color PDF и сравнивает контрольные пиксели,
а затем проверяет извлечённое монохромное изображение без сглаживания.

ФАКТИЧЕСКИЕ РЕЗУЛЬТАТЫ ПОД LINUX
results-core-linux.txt — 240 успешных проверок C#.
results-powershell.txt — 13 успешных проверок PowerShell.
results-pdf-independent.txt — 4 успешные независимые проверки PDF.
Эти файлы — результаты одного запуска; для новой проверки используйте скрипты.
SDK 8.0.426; Windows-кодеки и GUI под Linux не запускались.

Без аппаратуры нельзя подтвердить сетевую скорость, физический захват бумаги,
качество скана, отсутствие аппаратных замятий и поведение на конкретном DPI
монитора. Увеличение тайм-аута и фоновая обработка проверены кодом/компиляцией,
реальная производительность измеряется на вашем компьютере.

ПРОВЕРКА СКАЧАННОГО АРХИВА
python tests/check-package.py <скачанный-ZIP>
Только стандартная библиотека Python: сигнатура ZIP, CRC, отсутствие app/bin/obj
и бинарников, SHA256 каждого файла и полнота манифеста.

АВТООБРАБОТКА
ProcessingTests.cs добавляет 29 проверок наклона в обе стороны, границ,
бледных периферийных отметок, физического поля, масштаба предпросмотра,
серого края бумаги после поворота, отмены, контраста/цвета и Undo/Redo.
В папке результатов Core появляются processing-before.pgm и processing-after.pgm:
это синтетический текстовый лист для воспроизводимой визуальной проверки.
WindowsTests добавляет 14 проверок полного Bitmap: пиксели, DPI, обрезка,
сохранение цвета, PNG, расширение холста, режим Lineart и фильтр точек.
Эти 14 проверок скомпилированы, но здесь НЕ запускались.

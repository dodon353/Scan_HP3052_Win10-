# HP 3052 Scanner 0.7.1

Windows запускает D-Bus при входе пользователя и проверяет, отвечает ли служба, раз в минуту. Если D-Bus недоступна, задача пытается запустить её в Ubuntu. Это помогает после остановки WSL и избавляет от повторного запуска установщика при обычной остановке службы.

**Обновление с 0.7.0:** распакуйте архив, один раз запустите `DBUS-AUTOSTART.cmd` под той же учётной записью Windows, затем откройте `START.cmd`. Переустанавливать Ubuntu и заново вводить адрес сканера не требуется.

При первой установке автозапуск настраивает `INSTALL.cmd`. Для отключения выполните `DBUS-AUTOSTART.cmd off` из папки программы.

Проверка ZIP и тесты программы выполняются при сборке. Физическое сканирование на HP 3052 в CI не проверяется.

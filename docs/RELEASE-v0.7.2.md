# HP 3052 Scanner 0.7.2

- Программа проверяет D-Bus при открытии окна и перед обращением к сканеру. Если служба не отвечает, программа пытается запустить её в настроенной Ubuntu.
- Запуск работает через `START.cmd`, ярлык и прямой запуск `HP3052Scanner.exe`. Проверка выполняется без открытия консоли и без обращения к принтеру.
- Фоновая проверка через `DBUS-AUTOSTART.cmd` остаётся доступна, если служба нужна при закрытой программе.

**Обновление:** распакуйте ZIP и запустите `START.cmd`. Переустановка Ubuntu, повторный запуск `INSTALL.cmd` и ввод IP не нужны. Убедитесь, что ярлык ведёт к новой версии, если запускаете с рабочего стола.

Физическое сканирование и запуск установленной Ubuntu на компьютере пользователя не проверяются в CI.

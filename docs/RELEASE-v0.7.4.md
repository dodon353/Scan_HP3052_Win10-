# HP 3052 Scanner 0.7.4

Программа проверяет D-Bus и при необходимости запускает службу один раз при открытии приложения. Установщик больше не создаёт задачу Windows для фоновой проверки. Проверка службы перед каждым сканированием тоже удалена.

**Обновление:** распакуйте ZIP в новую папку. Если была установлена версия 0.7.1–0.7.3, один раз откройте `DBUS-AUTOSTART.cmd` из новой папки под той же учётной записью Windows: теперь он только удаляет старую задачу. Затем откройте `START.cmd`. Переустановка Ubuntu и повторный ввод IP не нужны.

# HP 3052 Scanner 0.7.0

Готовая программа для сетевого сканирования на HP LaserJet 3052 в Windows 10/11 x64 с русским интерфейсом.

- Сканирование со стекла и автоподатчика, предпросмотр и выбор области.
- Автовыравнивание наклона до ±5°, обрезка полей и улучшение читаемости с предпросмотром и отменой.
- PDF/JPG/PNG/TIFF/BMP и автоматическое имя при сохранении.
- EXE с иконкой сканера и встроенной .NET; собирать приложение не нужно.
- Инструкция для новичка и команды первоначальной настройки включены.

**Обновление:** закройте старую программу, распакуйте ZIP в новую постоянную папку и запустите `START.cmd`. Рабочую Ubuntu переустанавливать не нужно.

**Первая установка:** `INSTALL-UBUNTU.cmd` → при необходимости перезагрузка → `INSTALL.cmd` → `START.cmd`.

Для работы сканера требуются WSL1, Ubuntu 22.04 и HPLIP/SANE.

Контрольные суммы архива и EXE включены в отдельный файл `SHA256SUMS.txt` этого выпуска.

Сборка выполнена на Windows в GitHub Actions после проверок CoreTests, WindowsTests и PowerShell.

Сборка, иконка, содержимое single-file и целостность архива проверены; запуск итогового EXE на Windows в среде сборки не выполнялся.

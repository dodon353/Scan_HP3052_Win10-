HP 3052 SCANNER — версия 0.7.0
Простая инструкция для Windows 10 / 11, 64 бита

С ЧЕГО НАЧАТЬ
Нажмите на ZIP правой кнопкой → «Извлечь всё».
Распакуйте его в постоянную папку, например C:\HP3052Scanner.
Открывайте файлы из распакованной папки, а не из окна архива.
Готовая программа уже включена. Ничего собирать не нужно.
.NET встроен в EXE: отдельно устанавливать .NET и SDK не требуется.
Первый запуск может занять несколько секунд.

ЕСЛИ СКАНЕР УЖЕ РАБОТАЛ В ПРЕДЫДУЩЕЙ ВЕРСИИ
1. Закройте старое приложение.
2. Распакуйте новый архив в новую постоянную папку.
3. Откройте START.cmd двойным щелчком.
   Либо откройте папку app и запустите HP3052Scanner.exe.
4. Прежний адрес сканера, профили и текущий проект подхватятся автоматически
   при запуске под той же учётной записью Windows.
Ubuntu переустанавливать не нужно. INSTALL.cmd запускать для обновления
не требуется. Старый ярлык может вести в старую папку: пока пользуйтесь
новым START.cmd или создайте ярлык нового app\HP3052Scanner.exe вручную.

ЕСЛИ ЭТО ПЕРВАЯ УСТАНОВКА НА КОМПЬЮТЕРЕ
Нужны интернет, включённый сканер и подключение компьютера и сканера к сети.
1. Запустите INSTALL-UBUNTU.cmd двойным щелчком.
   Он проверит WSL и подготовит Ubuntu — среду для драйвера сканера.
   Если Windows запросит права администратора, подтвердите запрос.
   Если потребуется перезагрузка, перезагрузитесь и снова откройте
   INSTALL-UBUNTU.cmd. Дождитесь успешного завершения.
2. Запустите INSTALL.cmd. Он установит компоненты сканера в Ubuntu,
   попросит адрес сканера и создаст ярлыки. Введите IP самого HP 3052,
   а не компьютера. При обновлении используйте прежний рабочий адрес.
3. Откройте ярлык «HP 3052 Scanner» или START.cmd.
   Нажмите «Проверить связь» в приложении.
Первоначальная настройка выполняется один раз. WSL и Ubuntu нужны
для работы сканера; их нельзя удалять после установки.

КАК ОТСКАНИРОВАТЬ
1. Включите сканер. Для одного листа выберите «Стекло».
   Положите оригинал изображением вниз и закройте крышку.
2. Для обычного текста начните с A4, 300 DPI, «Оттенки серого».
3. Нажмите «Сканировать со стекла». Страница появится в списке.
4. Для следующих листов повторите сканирование — они добавятся в документ.
Для пачки листов используйте «Автоподатчик (пачка листов)» и верхний лоток.
При работе со стеклом верхний лоток держите пустым.
«Предпросмотр со стекла» показывает доступную область; для итогового
документа нажмите обычное сканирование или сканирование выделенной области.

КАК ВЫРОВНЯТЬ И УЛУЧШИТЬ СТРАНИЦУ
1. Выберите одну отсканированную страницу в списке.
2. Нажмите «Автообработка…» над изображением. На узком окне кнопка
   может находиться в меню дополнительных кнопок справа на панели.
3. Сравните оригинал слева и результат справа. Можно независимо включить
   выравнивание наклона, обрезку пустых полей и улучшение читаемости.
4. Обычно оставьте поле 3 мм и режим «Бережно».
   После смены параметров нажмите «Обновить предпросмотр».
5. Проверьте бледные буквы, подписи и номер страницы. Если всё устраивает,
   нажмите «Применить». «Отмена» оставит исходную страницу.
Ctrl+Z возвращает оригинал; Ctrl+Y возвращает обработку.
Автовыравнивание исправляет небольшой наклон до ±5°. Для страницы боком
есть поворот на 90°. При ошибочной обрезке отключите обрезку или измените поле.
История отмены действует до закрытия приложения.

КАК СОХРАНИТЬ
1. Выберите формат. Для многостраничного документа удобен PDF.
2. Для одного PDF на все страницы оставьте флажок «Один PDF» включённым.
   Чтобы сохранить все страницы, снимите флажок «Только выбранные».
3. Нажмите «Сохранить документ…».
4. Выберите папку в окне сохранения. Имя уже предложено автоматически;
   его можно изменить. Нажмите «Сохранить».
В PNG/JPG/TIFF/BMP каждая страница сохраняется отдельным файлом.
Для нескольких файлов к выбранному имени добавляются номера _001, _002 и т.д.
Для следующего документа нажмите «Новый документ».

ЕСЛИ ЧТО-ТО НЕ ПОЛУЧИЛОСЬ
• Нет связи: проверьте питание, сетевой кабель/сеть и адрес HP 3052.
  Если адрес изменился, введите новый и нажмите «Проверить связь».
• Изменённый лист не нравится: нажмите Ctrl+Z.
• После распаковки не найден EXE: извлеките архив целиком, сохраняя папки.
• Установка завершилась ошибкой: оставьте окно открытым и сохраните
  текст ошибки. Журнал программы открывается кнопкой «Журнал».

ЧТО НАХОДИТСЯ В АРХИВЕ
START.cmd — обычный запуск программы.
app\HP3052Scanner.exe — готовая программа с иконкой сканера.
INSTALL-UBUNTU.cmd и INSTALL.cmd — только первоначальная настройка.
installer — файлы настройки; сохраняйте эту папку рядом с командами.
Дополнительно — лицензии, сведения о сборке и сжатые исходники для
разработчика. Для повседневной работы открывать эту папку не нужно.

ИСХОДНИКИ СБОРКИ 0.7.0
Эта папка нужна только для разработки. Пользователю готового EXE сборка не нужна.
Содержимое соответствует EXE из основного архива, включая иконку scanner.ico.
Иконка создана для приложения; векторный оригинал — src/Assets/scanner.svg.
Для сборки установите .NET 8 SDK в Windows, затем запустите:
BUILD-WINDOWS.cmd portable
Результат: app/HP3052Scanner.exe, автономный single-file со сжатием.
Обычный BUILD-WINDOWS.cmd без portable создаёт меньший EXE, требующий
.NET Desktop Runtime 8 x64. Это другой режим, не режим готового EXE архива.
Исходная иконка и все её размеры в ICO включены в исходники.
RUN-TESTS.cmd выполняет тесты на Windows. Тесты и сохранённые результаты
предыдущей функциональной проверки 0.7.0 находятся в tests.
Текущая упаковка проверена сборкой Release win-x64 self-contained,
анализом PE/иконки и single-file содержимого и 13 PowerShell-проверками.
Windows GUI и реальный сканер здесь не запускались.
